### 👋 About Me

I'm a BEIT (Information Technology) student at **NCIT, Pokhara University**, based in Nepal. I like understanding how intelligent systems actually work — not just calling an API, but building the transformer, the retrieval pipeline, or the training loop myself first.

- 🔭 Currently building **RAG pipelines**, a **GPT-style LLM from scratch**, and shipping backend systems with FastAPI
- 🧪 Also competing in **Kaggle competitions** spanning medical imaging and computational biology
- 🌱 Learning philosophy: `Learn → Build → Break → Understand → Improve`
- 💬 Ask me about transformers, RAG internals, or FastAPI backend design

`PyTorch` `Transformers` `Fine-tuning`

`PyTorch` `EfficientNet` `Medical Imaging`
